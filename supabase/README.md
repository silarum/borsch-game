# Сервер 300 спартанцев и Telegram-админка

Эта папка содержит безопасную серверную реализацию. Она не включается в публичном клиенте до применения миграции, установки секретов и проверки staging-окружения.

## Что реализовано

- ровно 300 спартанцев с задуманным циклом `проиграл этап → может усилиться на следующем`, обязательной победой спартанца на пятом этапе и собственным демо-балансом;
- главный выключатель всех ботов;
- автоматический режим: боты появляются только когда реальных активных игроков меньше заданного порога;
- принудительный режим: пул заполняется ботами независимо от порога;
- целевой размер пула от 1 до 300;
- блокировка одного бота на время матча, защита от параллельной выдачи и журнал матчей;
- Telegram-админка с allowlist администраторов, секретом webhook и журналом всех изменений;
- режим техработ.

Боты выдаются только как явно обозначенные тренировочные соперники. Они не должны использоваться для скрытой подмены человека или в матче с реальными денежными ставками.

## Секреты Edge Functions

Нужны следующие server-side secrets:

- `TELEGRAM_BOT_TOKEN` — новый токен после отзыва опубликованного старого;
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка минимум 32 байта;
- `ADMIN_TELEGRAM_IDS` — числовые Telegram ID администраторов через запятую;
- `APP_ORIGIN=https://silarum.github.io`;
- `GAME_URL=https://silarum.github.io/borsch-game/`.

Токен нельзя помещать в репозиторий, клиентский JavaScript, сообщения об ошибках или URL, которые сохраняются в документации.

## Порядок запуска

1. Отозвать старый токен через `@BotFather` командой `/revoke` и выпустить новый.
2. Восстановить/активировать Supabase-проект.
3. Применить миграцию `202607170001_secure_spartans_and_admin.sql`.
4. Установить перечисленные секреты в Supabase Edge Functions.
5. Развернуть `matchmaking` и `telegram-admin` с `verify_jwt=false`. Каждая функция выполняет собственную обязательную проверку Telegram.
6. Развернуть безопасные заглушки `buy-srum`, `process-withdrawal` и `update-balance` поверх старых небезопасных версий.
7. Установить Telegram webhook на URL функции `telegram-admin` с параметром `secret_token`, равным `TELEGRAM_WEBHOOK_SECRET`.
8. Проверить команды `/status`, `/bots_off`, `/bots_on`, `/threshold 10`, `/target 20`.
9. Только после staging-проверки переключить `matchmakingEnabled` в `js/security.js` на `true`.

## Команды с телефона

- `/status` — состояние проекта, онлайн и активные боты;
- `/bots_on`, `/bots_off` — включить или полностью отключить 300 спартанцев;
- `/auto_on` — включать спартанцев только при нехватке реальных игроков;
- `/auto_off` — принудительно заполнять тренировочный пул;
- `/threshold 10` — порог реальных игроков;
- `/target 20` — целевой размер пула.

Кнопки с теми же действиями появляются после `/admin` или `/start` у разрешённого администратора.
