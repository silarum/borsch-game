Политика конфиденциальности

Последнее обновление: 17 июля 2026 года.

Какие данные использует демо

При запуске внутри Telegram приложение может получить публичный идентификатор пользователя и имя из Telegram Mini App. При добровольном подключении TON Connect приложение получает публичный адрес кошелька. Приватные ключи и seed-фразы приложению недоступны.

Где хранятся данные

Игровые очки, настройки, клубы, задания и другой демо-прогресс сохраняются только в локальном хранилище браузера. Облачная синхронизация и финансовые операции в текущей версии отключены.

Удаление

Демо-данные можно удалить очисткой данных сайта или хранилища Telegram Mini App на своём устройстве. После очистки восстановить их невозможно.

Сторонние сервисы

Для работы внутри Telegram загружается официальный Telegram Web App SDK. Для добровольного подключения кошелька используется TON Connect. Эти сервисы обрабатывают данные по собственным правилам.
