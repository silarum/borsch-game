# Крипто Борщ

Telegram Mini App с короткими игровыми сессиями: добыча RUMIR, пятиэтапные дуэли за SRUM, игровые пулы, 300 спартанцев, клубы, задания, магазин и рефералы.

## Текущий статус

Проект работает как безопасная демо-игра. RUM и SRUM в этой версии — только локальные игровые очки. Покупка, обмен, вывод, денежные награды и облачная синхронизация намеренно отключены до появления защищённого сервера.

Это важно: нельзя включать финансовые функции простым изменением `financialFeaturesEnabled`. До запуска нужны серверная проверка Telegram `initData`, проверка TON-транзакций по блокчейну, атомарный ledger балансов, роли администратора, RLS и журнал аудита.

Серверная экономика пулов, казна, логика 300 спартанцев и защищённая мобильная Telegram-админка подготовлены в папках `supabase/` и `admin/`. Они остаются выключенными, пока владелец не отзовёт раскрытые токены обоих ботов, не установит новые токены в server-side secrets и не активирует Supabase-проект.

## Экономика пяти этапов

- штрафы по этапам: 10%, 20%, 40%, 80%, 100% от оставшегося взноса;
- 70% штрафа проигравшего получает победитель;
- 30% штрафа автоматически поступает в казну проекта;
- остаток взноса проигравшего остаётся заблокированным для продолжения с первого этапа;
- майнер-победитель пятого этапа остаётся на пятом этапе до первого поражения;
- спартанец после поражения на этапе N входит на этап N+1 и гарантированно выигрывает; на пятом этапе он всегда выигрывает, после победы его цикл сбрасывается на первый этап.

## Локальный запуск

1. Откройте терминал в папке проекта.
2. Запустите `python3 -m http.server 8080`.
3. Откройте `http://localhost:8080`.

Для проверки кода нужен Node.js 20 или новее:

```bash
npm test
```

## Безопасность

- Публичный клиент не содержит токен Telegram-бота или админ-пароль.
- Клиент не пишет напрямую в таблицы Supabase.
- Денежные операции и клиентское начисление TON/USDT отключены.
- TON Connect используется только для подключения публичного адреса кошелька.
- Пользовательский текст экранируется, внешние ссылки ограничены HTTPS.
- GitHub Actions автоматически проверяет синтаксис, секреты, ссылки и размер изображений.
- 300 спартанцев имеют собственные балансы 30–300 SRUM на старте, добывают RUMIR, переходят между состояниями и заполняют игровые пулы по серверным условиям.
- Спартанцы не остаются на пятом этапе: повторяемый пятый этап предназначен только для майнеров-игроков.
- Telegram-админка принимает команды только от разрешённых числовых Telegram ID и только через webhook с секретом.
- Полная админ-панель открывается отдельной страницей внутри админ-бота и управляет пулами, заданиями, спартанцами, казной и режимом техработ.

## Обязательное действие владельца

Токены игрового и административного Telegram-ботов были раскрыты. Оба необходимо отозвать через `@BotFather` командой `/revoke` и выпустить заново. Новые токены нельзя отправлять в чат, добавлять в HTML/JavaScript или коммиты — они должны храниться только в секретах серверной среды.
