# Крипто Борщ V9

V9 объединяет актуальный главный экран Home V10 и Premium V7 из `main` с завершённым боевым модулем Hungry Wolves V8.

## Что вошло

- 9 уникальных бойцов и 436 зарегистрированных игровых кадров.
- Отдельные циклы движения, атак, блока, урона, суперприёмов и нокдауна.
- Мобильное аркадное управление, звук и команда `Fight!`.
- Выбор бойцов, турниры и рейтинговые лестницы.
- Баланс-симуляция 10 800 боёв.
- Проверка сигнатуры и целостности каждого обязательного PNG.

## Исправление V9

На мобильной арене бойцы больше не перекрывают друг друга: минимальная дистанция увеличена до 22% ширины арены, границы перемещения сужены, а ширина спрайта на экранах до 390 px уменьшена до 55%.

## Проверка

```bash
npm run check
```

Команда запускает тестовый набор и детерминированную симуляцию баланса всех девяти бойцов.
