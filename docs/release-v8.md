# «Крипто Борщ: Голодные волки» — V8 Final

## Состав релиза

- девять выбираемых бойцов с разными школами, характеристиками, фирменными комбинациями и суперприёмами;
- 436 подключённых прозрачных покадровых кадров;
- полные состояния боя: стойка, ходьба, прыжок, присед, уклон, атаки X/Y/Z, блок B, ярость R, получение урона и нокдаун;
- вступление и победная поза Fenrir Block;
- адаптивный ИИ, дистанция, выносливость, ярость, оглушение, отбрасывание, раунды и K.O.;
- выбор бойца, турнирная квалификация, личная и клубная рейтинговые лестницы;
- WebAudio-эффекты и голосовая команда `Fight!`;
- мобильные элементы управления и адаптивные правила для экранов 390 и 340 пикселей.

## Проверки

- `npm run check`: 23/23 проектных теста;
- 10 800 детерминированных симуляций всех пар бойцов;
- средняя победная доля каждого бойца находится в коридоре 42–58%;
- 453 PNG в каталогах анимации полностью декодируются без ошибок;
- обязательные 436 кадров проверяются тестами на наличие, формат и привязку к анимационным состояниям;
- `index.html` и выборочные игровые кадры отдаются локальным HTTP-сервером с кодом 200.
